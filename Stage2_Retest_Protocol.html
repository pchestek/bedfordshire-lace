Stage 2 Re-Test Protocol

Bedfordshire Lace Designer  |  Date: __________  |  Tester: __________

This is a focused re-test of five fixes applied after the Stage 2 testing session. Only these specific behaviours need to be validated before proceeding to Stage 3.

1 — Startup & Keyboard Focus

  • Launch the app. Do not click anywhere on the canvas.
  • Press T — the Trail button should activate and hint text should appear in the options bar (below the menu).
  • Press S — should return to Select tool.
  • Press Esc — should also return to Select tool.
  • Press T again and confirm hint text returns.

2 — Start-of-Trail Artifact

  • Press T to activate the Trail tool.
  • Click once to place the first waypoint.
  • Move the cursor slowly away from that point.
  • Expected: no geometry visible while cursor is within ~2 mm of the start point. Preview should appear cleanly once cursor moves further away — no star or burst shape.

3 — H-Key Temporary Pan (Bamboo Pad)

  • Activate the Trail tool (T), either idle or mid-draw.
  • Hold H — cursor should change to a hand.
  • Drag with the stylus/touchpad — canvas should pan.
  • Release H — should return to Trail tool automatically.
  • Repeat, but instead of dragging, use the ← → ↑ ↓ arrow keys while holding H — canvas should scroll.

4 — Shift+Click Sharp Corners

  • Press T to activate Trail tool.
  • Click to place 2 – 3 normal (smooth) waypoints.
  • Hold Shift and click to place a sharp-corner waypoint.
  • Add 1 – 2 more normal waypoints after it.
  • Double-click to finish the trail.
  • Expected: the Shift+click point is a sharp angle; surrounding points remain smooth curves.

5 — Closed Trail

  • Press T to activate Trail tool.
  • Place 4 or more waypoints in a rough loop shape (do not close yet).
  • Move the cursor back toward the first waypoint.
  • Expected: a blue snap indicator appears when close to the first waypoint.
  • Click while the blue indicator is visible — the trail should close into a smooth loop.
  • Verify pinholes appear along both edges all the way around the closed shape, with no open gap at the join.
